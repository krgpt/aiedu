# AI EDU NEXUS — AI 초급~중급 8회 과정

`AI 초급~중급 8회 교육 과정 요약.txt`의 흐름을 중심으로 제작한 교육 과정 소개 웹사이트입니다.
`pdf/` 폴더의 자료(4대 LLM 특성, Agent 생태계, AI 인체구조, 필수 용어)를 참고해 커리큘럼과 지식 섹션을 구성했습니다.

## 파일 구성

```
ai-edu-nexus/
├─ index.html   # 페이지 구조와 콘텐츠
├─ styles.css   # 디자인, 다크/라이트 테마, 반응형 레이아웃
├─ script.js    # 탭, 아코디언, 용어 검색, 테마, 복사, 스크롤 애니메이션
└─ README.md
```

## 미리보기

`index.html`을 브라우저로 열면 바로 확인할 수 있습니다. 별도의 빌드나 서버는 필요하지 않습니다.

## 배포

정적 사이트이므로 아래 서비스에 폴더를 그대로 올리면 됩니다.

- **Netlify**: 폴더를 드래그 앤 드롭하거나 Git 저장소 연결 (build command 없음, publish directory `/`)
- **Vercel**: 프로젝트 Import 후 Framework Preset을 `Other`로 선택
- **GitHub Pages**: 저장소에 파일을 올린 뒤 Settings → Pages에서 배포 브랜치 선택

1. Hero — 과정 소개와 8회 학습 경로

6. 수강 안내 — 수업 구성, 추천 대상, 준비물, FAQ
