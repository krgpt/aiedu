Q FAQ

자주 묻는 질문

코딩을 전혀 몰라도 들을 수 있나요?

네. 이 과정은 프로그래밍 문법을 가르치는 과정이 아닙니다. 6회차에서는 AI에게 HTML/CSS/JavaScript 구조를 설명하고 수정을 요청하는 방식으로 웹사이트를 만듭니다.

AI 유료 결제가 꼭 필요한가요?

필수가 아닙니다. 1회차부터 무료 수준의 기능을 중심으로 실습합니다. 이미 가입한 모델이 있으면 그것을, 없다면 Gemini를 중심으로 진행합니다.

초급과 중급은 어떻게 나뉘나요?

1–2회차는 AI·LLM·프롬프트와 파일 분석을 다루는 기초 구간, 3–5회차는 Agent와 Opencode·Egolite를 다루는 중급 구간, 6–8회차는 웹사이트·앱 제작과 배포를 다루는 실전 구간입니다.

수업이 끝나면 무엇이 남나요?

실제 URL로 접속 가능한 웹사이트, 개인 GitHub Repository, 앱 제작 실습 결과물, 그리고 4대 LLM·Agent·AI 코딩 도구를 다루는 경험이 남습니다.

준비물이 부족하면 수강이 어렵나요?

노트북과 Chrome 브라우저만 있으면 시작할 수 있습니다. Google 계정은 1회차 전에, GitHub 계정은 7회차 전까지 준비하면 됩니다.
